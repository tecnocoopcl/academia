# Plantilla de curso

Punto de partida para un curso de academia: copia esta carpeta a un repo
propio, edita `curso.json` e `index.html`, y publícalo (por ejemplo en
GitHub Pages con un subdominio de `tecnocooperativa.cl`). Luego propone un
cambio a `cursos/registro.json` de academia con la URL de tu `curso.json`.

Nada aquí es obligatorio salvo `curso.json`. Ver
[la especificación](../docs/ESPECIFICACION-curso.md) y
[la guía de diseño](../docs/GUIA-diseno.md).
